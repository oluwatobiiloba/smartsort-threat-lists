SmartSort threat lists

This address serves the lists of known developer threats that SmartSort, a Mac app, can download. It isn't meant to be read in a browser: the app asks for the files below by name, checks the manifest's signature, and ignores anything it can't verify.

Downloading is off in SmartSort until you turn it on. Requests carry no identifier, and nothing about your files is ever sent.

The current set

  • v1/manifest.json
    Which files are in the set, with each one's size and SHA-256.
  • v1/manifest.json.sig
    The Ed25519 signature SmartSort checks before it uses anything.
  • v1/NOTICE.txt
    Where each list and rule comes from, and its licence.
